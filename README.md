# رائد الحربي · كَان — البورتفوليو

موقع أعمال [رائد الحربي](mailto:raeddesign25@gmail.com) — مصمم جرافيك سعودي: هويات المواسم والتعاونات، سوشال وحملات، وجلسات تصوير وفيديو للمنتجات بالذكاء الاصطناعي.

موقع ثابت (HTML/CSS/JS) بدون أي أدوات بناء — يفتح مباشرة من `index.html`.

## البنية

```
index.html            الرئيسية: الهيرو، التصوير والفيديو، شبكة «الأعمال» بفلاتر الخدمات، العملاء، عن رائد، تواصل
ai-gallery.html       «جلسات التصوير والفيديو»: جلسات التصوير (عطور · مطاعم · منتجات) + مقاطع قبل ← بعد
projects/             صفحة لكل مشروع (tecno · bp · flatty · boulevard · winter · vox · reef · osma · dawar · dafoor)
assets/
  css/styles.css      التنسيقات المشتركة + الرئيسية
  css/gallery.css     تنسيقات صفحة الجلسات
  js/main.js          الهيدر، قائمة الجوال، روابط الأقسام
  js/home.js          الرئيسية: شبكة اللقطات، فلاتر الأعمال، زر واتساب
  js/gallery.js       صفحة الجلسات: التبويبات، عارض الصور، مقارنة الفيديو
  js/shoots.js        بيانات جلسات التصوير (window.SHOOTS)
  js/videos.js        بيانات مقاطع قبل ← بعد (window.VIDEOS)
  fonts/              خط Camel ‏WOFF2 (300 · 400 · 700 · 800)
  video/              مقاطع قبل/بعد وملصقاتها (poster)
  images/
    brand/            الشعار، الأيقونات، صورة المشاركة، شعارات العملاء (clients/ بارتفاع 60px)
    cards/            أغلفة بطاقات «الأعمال» وبطاقات «المشروع التالي» (900×600)
    shoots/<slug>/    صور الجلسات: NN.jpg كاملة و NN-t.jpg مصغّرة 720×540
    projects/<slug>/  صور صفحات المشاريع
    collabs/          صور التعاونات (boulevard · winter · vox-bp)
```

## إضافة عمل جديد

ما يصير قسم جديد أبداً — كل عمل يروح لواحد من ثلاث أماكن:

1. **بطاقة جديدة** في شبكة `#work` داخل `index.html` — فقط لمشروع كبير مستقل (هوية كاملة / تعاون / حملة كبيرة). الغلاف في `assets/images/cards/<slug>.jpg` بمقاس 900×600، و`data-services` بالخدمات اللي فيه.
2. **فصل داخل صفحة البراند** الموجودة `projects/<slug>.html`.
3. **جلسة أو مقطع** في `assets/js/shoots.js` أو `assets/js/videos.js` (تظهر تلقائياً في `ai-gallery.html`).

قبل النشر: كل صفحة مشروع فيها سطر «دوري:» صريح، وأي مقطع فيه شخص يحتاج موافقته.
